# Contributing

This repository is the methodology a real firm examines against, so changes
to the method itself are ours to make. Everything else is open.

**Found an error?** A typo, a broken reference, wording that reads two ways:
open an issue or a pull request. These are welcome and usually merge fast.

**Disagree with a call?** A calibration example that softens something it
should not, pass criteria that miss a case, a control that is too narrow or
too broad: open an issue naming the control and attribute id, and say why.
This is the feedback we value most.

**Prefer email?** cpa@chiarohq.com reaches us directly.

Method changes prompted by outside feedback are credited in
[CHANGELOG.md](CHANGELOG.md), unless you would rather not be named.
